# T2601 — API Arduino
> Modular I/O expansion board based on the ATmega328P.

This document is a guide line to install every components on Extentions boards PCBs

As shown on the photo you will need the following list of components :
-2x 16P (2x8) male IDC Connectors
-2x XH P2.54 male Connectors
-1x 2x3 P2.54 PinSocket
-1x 1x4 P2.54 PinSocket
-4x 1x10 P2.54 PinSocket
-2x 8Pos 2.54P Screwterminal
-2x 2Pos 2.54P Screwterminal
-2x Capacitor THT (modele et valeur a péciser)
-1x THT Schottky Diode (Optionnal, only needed if powering from programmer)
